# PRD 검증 계획

## 검증 원칙

문서의 완료는 제품 가설의 증명이 아니다. 구현 시작 전에는 아래의 위험을 가장 값싸게 줄이고, 각 게이트의 증거를 `decision-log`에 기록한다. 법률·공급자 정책 판단은 최신 원문과 담당자 검토가 없으면 `보류`다.

| 게이트 | 검증할 위험 | 방법 | 통과 기준 | 실패 시 결정 |
|---|---|---|---|---|
| V1 수요 | 사용자가 요청 형식을 이해하지 못함 | 5–10명 인터뷰, 클릭 가능한 요청 플로우 | 5명 중 4명 이상이 스스로 제출·승인 | 필드/카피를 단순화하고 재시험 |
| V2 숏폼 품질 | 15초가 장면 의도를 못 담음 | 서로 다른 3개 오리지널 브리프의 샘플·음소거 시청 | 품질 루브릭 80% 이상 | 컷 예산, 자막, 길이 재설계 |
| V3 권리·안전 | 금지 요청이 제작으로 흘러감 | 정책 테스트 세트와 운영자 테이블탑 | 전부 차단 또는 검토 대기 | 규칙·에스컬레이션 보완 |
| V4 공급자 실현성 | 결과 규격·비용·대기 시간·권리가 불명확 | 2개 이상 후보의 동일 브리프 벤치마크 | 승인된 최소 품질/비용/약관 기준 충족 | 공급자 교체 또는 MVP 축소 |
| V5 신뢰 | 공개/삭제/공유가 사용자 의도와 다름 | 프로토타입 사용성 테스트 | 모든 참가자가 private·철회·삭제를 수행 | 정보 구조·확인 단계 보완 |

## V2 품질 루브릭

각 샘플은 0/1로 채점한다. 5개 중 4개 이상이면 통과다.

1. 1080×1920 또는 동등한 9:16 재생이 된다.
2. 첫 2초 안에 인물·상황·긴장 중 하나가 명확하다.
3. 한 감정 또는 갈등만 다루며, 결말이 이해된다.
4. 음소거에서도 자막이 안전 영역 안에서 읽힌다.
5. 특정 기존 작품의 캐릭터·대사·시각적 고유성을 복제하지 않는다.

## V3 정책 테스트 세트

최소 20개 요청으로 시작하며 아래 유형을 모두 포함한다. 테스트 결과에는 입력 요약, 자동 판정, 사람 검토 판정, 사유 코드, 최종 상태를 남긴다.

| 유형 | 기대 경로 |
|---|---|
| 오리지널 관계·장면 | 통과 후 스토리보드 |
| 작품명만 언급한 ‘분위기’ 요청 | 추상화 안내 또는 검토 |
| 특정 캐릭터·로고·고유 대사·정확한 장면 재현 | 차단 또는 오리지널 재작성 |
| ‘내가 권리를 보유’ 주장 | 증빙 검토 대기 |
| 실존 배우·연예인·지인 얼굴/목소리 재현 | 차단 또는 권한 증빙 검토 |
| 미성년자 성적화, 개인정보, 사칭, 혐오/괴롭힘, 과도한 고어 | 차단 또는 검토 대기 |

## V4 공급자 벤치마크 카드

공급자 선정 전 각 후보에 동일한 세 개의 오리지널 브리프를 실행한다. 공급자 이름이 아닌 `provider_id`로 결과를 보관해 교체 가능하게 한다.

| 항목 | 기록값 |
|---|---|
| 기능 | 텍스트→영상, 이미지/음성 입력 필요 여부, 9:16/15초 지원, 자막 처리 |
| 품질 | V2 점수, 인물/장면 일관성, 실패율, 워터마크 |
| 운영 | 평균·P95 대기 시간, 재시도 API, 웹훅/폴링, 결과 URL 만료 |
| 비용 | 성공·실패·재생성별 추정 원가와 월 상한 |
| 권리 | 상업 이용, 사용자 콘텐츠 학습, 보존·삭제, 지역/연령 제한 |
| 보안 | 데이터 처리 위치, 접근 제어, 감사 자료, 비밀키 운영 |

선정 기준은 구현 전에 별도 ADR로 수치화한다. 약관 확인이 안 된 후보는 품질이 좋아도 출시 후보가 아니다.
