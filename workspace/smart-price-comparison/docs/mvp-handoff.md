# Smart 가격비교 MVP handoff

- 상태: MVP 완료
- 표시명: `Smart 가격비교`
- 프로젝트 경로: `workspace/smart-price-comparison`
- 대상: 소비자, 자영업자, 대행업체

## 완료 범위

- 메뉴 판매가에서 원재료비, 인건비, 가스비, 포장비, 수도세, 전기세를 차감해 총비용, 예상 이익, 이익률, 원가율과 손익 상태를 계산한다.
- 상품 정상가와 명시적 할인가로 실구매가, 절감액, 할인율을 계산하고 10g, 100g, 10ml당 가격을 비교한다.
- 같은 기준 단위에서 동률을 포함한 최저가를 강조한다.
- 지원 브라우저에서는 QR/EAN/UPC 코드를 카메라로 읽고, 미지원·미등록 환경에서는 수동 코드와 상품 정보 입력으로 같은 흐름을 완료한다.
- 샘플 데이터와 사용자 입력을 버전이 있는 `localStorage` 스냅샷으로 저장하며 손상 데이터는 안전한 샘플로 복구한다.
- 데스크톱과 모바일에서 세 페르소나 전환, 메뉴 수익 계산, 상품 추가·삭제·비교를 사용할 수 있다.
- 저장소의 실행 폴더 명칭을 `work`에서 `workspace`로 전환하고 활성 경로 참조와 기존 프로젝트 회귀를 확인한다.

## 검증 기준

프로젝트 루트에서 다음 한 명령으로 단위 테스트, 타입 검사·생산 빌드, 데스크톱·모바일 브라우저 흐름을 검증한다.

```powershell
npm run verify
```

MVP 완료 시점의 기대 결과는 단위 테스트 16건 통과, 생산 빌드 통과, Playwright 7건 통과와 데스크톱에서 의미 없는 모바일 전용 확인 1건 제외이다. 카메라 자원 해제는 성공·취소·시간초과 단위 테스트로 검증하며 실제 카메라 권한은 HTTPS 또는 localhost의 지원 브라우저에서 수동 확인한다.

## 운영 제약

- 마트 가격은 실시간 외부 시세가 아니라 로컬 샘플 또는 사용자가 입력한 값이다.
- 데이터는 현재 브라우저와 기기에만 저장된다.
- 카메라 스캔은 상품 코드 취득 기능이며 상품명, 매장, 가격, 용량을 외부에서 자동 수집하지 않는다.
- 세금, 배달 플랫폼 수수료, 월 공과금의 판매량 기반 배분은 현재 계산에 포함하지 않는다.
