# Arena Strike 배포 선택 로비 및 캐주얼 사운드 설계

## 의도

현재 Phaser 게임의 시작 경험을 선택 로비 중심으로 확장한다. 플레이어는 게임 진입 전에 무기, 맵, 적 수, 날씨, 캐릭터/오브젝트 스킨을 확인하고 선택한다. 게임 내 피드백은 충돌, 발사, 무기 교체, 캐주얼 배경 루프 사운드로 강화한다.

## 목표

- 클래식 경로에 무기·맵·적 수·날씨·스킨 선택 UI 제공
- 기존 3개 맵과 기존 자산/카탈로그를 선택 화면의 실제 썸네일과 라벨로 재사용
- 적 수 선택은 1~4명 모델을 준비하고 1명에서도 기존 동작을 보존
- 비, 눈, 맑음, 태풍 날씨를 데이터 선택값으로 연결하고 속도·시야·바람·동결 규칙을 표시
- 발사, 충돌/피격, 무기 교체, 배경 음악을 기존 생성형 오디오 계약으로 통합
- 선택값을 새로고침 가능한 URL 상태로 저장

## 비목표

- 이번 슬라이스에서 신규 유료 결제 백엔드 구현
- 기존 저작권 자산을 새로 내려받거나 외부 생성 API를 런타임에 호출
- 기존 게임 밸런스와 저장 데이터를 무단 변경
- 한 번에 Phase 13 전체 애니메이션/월드 프로모션을 완료

## 접근법

1. 데이터 기반 선택 로비: 기존 `ArcadeStageCatalog`, `VisualAssetCatalog`, `ActorSkinCatalog`, `WorldObjectSkinCatalog`, `WeatherLogic`을 조합한다. 추천안이며 기존 경계와 가장 잘 맞는다.
2. 전투 우선: 적 다중화와 날씨부터 구현한 후 선택 UI를 붙인다. 전투 검증은 빠르지만 시작 상태 계약이 늦어진다.
3. 비주얼 우선: 새 썸네일/스킨 이미지를 먼저 제작한다. 화면은 빨리 좋아지지만 선택값과 플레이 검증이 늦어진다.

선택: 1번. 기존 시스템 재사용, URL 재현성, 단계별 회귀 검증이 가능하기 때문이다.

## 설계

### Presentation

`DeploymentPicker`가 무기·맵·적 수·날씨·스킨 카드를 렌더링하고 submit 시 정규화된 query string을 만든다. 기존 Cozy Arcade picker와 분리해 클래식 경로에도 적용한다.

### Business

`DeploymentSelection`이 선택 가능한 ID와 기본값을 정의한다. 잘못된 query는 기본값으로 복구한다. `enemyCount`는 1~4로 제한하며 초기 런타임은 1명을 보존하고 다중 적 스폰 계약을 다음 세로 슬라이스에서 소비한다.

### Audio

`SoundCueKey`와 tone map에 `impact`, `weapon.swap`, 무기별 `fire`, `ambient.casual` 계열을 추가한다. 배경음은 낮은 볼륨의 반복 패턴으로 분리하고 SFX cap/cooldown을 유지한다.

### Data and lifecycle

선택값은 URL에 저장하고 Phaser scene 생성 시 한 번 읽는다. 오디오 Context는 사용자 입력 이후에만 활성화한다. Scene shutdown 시 배경 루프를 중지한다.

## 수용 기준

- 선택 로비에서 3개 이상 맵 썸네일, 무기 이미지, 적 수 1~4, 4종 날씨, 캐릭터/오브젝트 스킨이 표시된다.
- submit 후 query가 정규화되고 새로고침해도 선택이 유지된다.
- 기존 기본 경로의 전투 테스트와 기존 69-file/423-test 기준에 회귀가 없다.
- 사운드 계약 테스트가 발사, 충돌, 교체, 배경 루프를 검증한다.
- 배경 루프와 효과음이 동시에 재생될 때 음량/동시 재생 제한을 넘지 않는다.
