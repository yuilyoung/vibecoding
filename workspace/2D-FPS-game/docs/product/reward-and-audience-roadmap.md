# ArenaStrike 보상 및 타깃 운영안

## 제품 방향

ArenaStrike는 3~8분 안에 한 판을 끝내고, 승리 직후 보상과 다음 목표를 보여주는 캐주얼 2D 아레나 게임으로 운영한다.

핵심 루프는 다음과 같다.

`짧은 결투 → 승리 보상 → 랭킹/해금 확인 → 다음 결투`

## 승리 보상

- 승리 점수: 라운드 승리 수, 패배 라운드 수, 빠른 클리어 보너스로 산정
- 코인: 승리 점수의 10%를 기본 지급
- 랭킹 포인트: 승리 수와 라운드 안정성을 반영
- 등급: Bronze Spark, Silver Star, Gold Comet, Platinum Pulse, Diamond Nova

현재 보상 계산은 `src/domain/rewards/VictoryRewardLogic.ts`에 구현되어 있으며, 최종 승리 시 HUD 이벤트에 `VICTORY +점수 SCORE / +코인 COINS`가 표시된다.

## 해금과 상점

무기 해금 후보:

- Tracking Missile: Silver 해금
- Machine Gun: Gold 해금
- Prism Beam: Platinum 해금

상점 아이템:

- Heart Battery: 최대 HP +10
- Turbo Sneakers: 이동속도 +5%

아이템은 유료 결제보다 먼저 게임 내 코인 소비로 검증하고, 이후 스킨 패스·시즌 상품으로 확장한다.

## 캐릭터 스킨

랭킹별 무료 해금 후보를 4종으로 구성한다.

- Bubble Pop: Bronze
- Neon Kitten: Silver
- Sunny Pup: Gold
- Pixel Cloud: Platinum

각 스킨은 짧은 세션에서 식별이 쉬운 강한 색상 3개와 단순한 실루엣을 사용한다. 시각 자산 적용 단계에서는 현재 아케이드 캔버스 생성기와 동일한 2D 스타일을 유지한다.

## 타깃 사용자

주 타깃은 10~29세, 특히 짧은 여가 시간에 모바일·웹 게임을 즐기는 여성 사용자다.

- 첫 판 진입: 30초 이내
- 한 판 길이: 3~8분
- 승리 후 보상 확인: 5초 이내
- 다음 목표: 항상 하나만 명확하게 노출
- 실패 화면: 재도전 버튼과 작은 보상 진척도만 표시

테트리스의 즉시 재시작, 펫 키우기의 수집·애착, 브롤스타즈의 짧은 대전·스킨 수집을 참고하되, 과도한 결제 압박과 복잡한 메타 시스템은 피한다.

## 다음 구현 순서

1. 보상 요약 패널: 점수·코인·랭크 뱃지·해금 항목 표시
2. RewardStorage: 로컬 저장 기반 코인·랭크·스킨 보유 상태 저장
3. 상점 화면: HP/속도 업그레이드 구매 및 적용
4. 스킨 카탈로그: 4종 실제 런타임 비주얼 연결
5. 온라인 랭킹: 인증·부정행위 방지·서버 저장을 포함한 별도 백엔드 작업
