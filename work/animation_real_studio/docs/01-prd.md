# PRD — Animation Real Studio

| 항목 | 내용 |
|---|---|
| 버전 | 0.1 (검증 전 가설) |
| 제품 한 줄 | 팬의 아이디어를 권리 안전한 오리지널 실사풍 숏폼으로 기획하고 전달하는 AI 제작 스튜디오 |
| MVP 대상 | 자신의 감정적 장면 아이디어를 SNS용 콘셉트 영상으로 보고 싶은 일반 사용자·크리에이터 |
| 핵심 결과 | 승인된 기획안에서 15초 9:16 영상, 자막, 썸네일, 버전 이력을 생성·비공개 전달 |

## 문제와 가치

사용자는 좋아하는 애니메이션에서 느낀 감정이나 관계를 실사 영상으로 보고 싶어 하지만, 이를 안전한 제작 언어로 바꾸고 짧은 영상으로 완성할 도구가 없다. Animation Real Studio는 자유 서술을 **제작 가능한 기획안**으로 정리하고, 특정 원작을 복제하지 않는 오리지널 콘셉트 영상으로 전달한다.

성공은 “유명 IP를 똑같이 재현함”이 아니라 “사용자가 말한 감정과 장면의 의도를, 자신 있게 공유할 수 있는 새로운 15초 영상으로 만남”이다.

## 범위

### MVP에 포함

- 랜딩 페이지, 정책 안내, 로그인, 개인 프로젝트 보관함
- 단계형 요청 폼과 임시저장
- 비식별 오리지널 사진 또는 무음 짧은 영상 한 건의 선택 참조 입력
- 권리·안전 사전 검사, 차단/재작성 안내, 운영자 검토 대기
- 기획안·스토리보드 제시와 사용자 승인/수정
- 비동기 생성 작업, 상태 표시, 실패 재시도
- MP4, 내장 자막, VTT/SRT, 썸네일, 설명 초안, 생성 버전 메타데이터 전달
- 삭제 요청, 만료, 신고, 철회 가능한 공유 링크

### MVP에서 제외

- 유명 IP·캐릭터·고유 대사·장면의 충실한 재현
- 권한 없는 실존 인물의 얼굴·음성·행동 재현 또는 딥페이크
- 원작 애니메이션 스틸/클립/음원, 실존 인물 사진·영상, 제3자 상업 영상 업로드, 공개 추천 피드, 자동 SNS 게시
- 다분량 편집기, 결제·크레딧, 협업 워크스페이스, 라이선스 증빙 B2B 주문

## 핵심 사용자 흐름

```text
랜딩 → 로그인 → 요청 초안 → 권리·안전 검사 → 기획안/스토리보드
      → 사용자 승인 → 생성 대기열 → 생성/품질 검사 → 개인 보관함
      → 다운로드 또는 (선택) 만료 가능한 공유 링크/갤러리 공개
```

## 요청 입력 계약

| 단계 | 필드 | 규칙 |
|---|---|---|
| 1. 장면 의도 | 장면 설명 (필수) | 30–700자. “누가, 무엇을 겪고, 어떤 감정을 남길지”를 쓴다. |
| 1. 장면 의도 | 인물·관계 | 이름 대신 역할, 외형 범주, 관계, 감정을 구조화한다. 실존 인물 이름·사진은 받지 않는다. |
| 1. 장면 의도 | 참조 미디어 (선택) | 권리를 가진 비식별 사진 1장 또는 무음 15초 이하 영상 1개. 배경·조명·구도·움직임 참고에만 쓰며, 격리·정책 검사를 통과한 정제본만 생성에 사용한다. |
| 2. 권리 | 원작 관계 (필수) | `오리지널` / `내 소유 또는 라이선스 보유` / `기존 작품에서 영감만 받음` 중 하나를 고른다. |
| 2. 권리 | 출처·권리 증빙 | MVP에서는 텍스트 고지만 받는다. 라이선스 보유 주장은 사람 검토 전 생성하지 않는다. |
| 3. 연출 | 장르·시대·장소·조명·카메라 | 선택지+자유 입력. 특정 작품명, 로고, 고유 복장·소품을 연상시키는 조합은 재작성 안내한다. |
| 3. 연출 | 대사/내레이션·자막 언어 | 짧은 원문만 허용하며 저작권 있는 대사 복제는 차단한다. MVP 기본 언어는 한국어, 영어·일본어는 검증 후 추가한다. |
| 3. 연출 | 길이 | MVP는 15초 고정이다. |
| 4. 확인 | 권리·동의 확인 (필수) | 제3자 IP·초상·음성의 무단 사용 금지, 참조 미디어의 권리·처리·삭제 일정, 정책 위반 시 거부/삭제 가능성에 동의한다. |

## 산출물 계약

각 승인 버전은 다음을 하나의 `delivery manifest`로 연결한다.

| 자산 | MVP 규격 | 사용자 화면 |
|---|---|---|
| 영상 | 1080×1920, 9:16, 15초, MP4(H.264/AAC) | 인라인 재생·다운로드 |
| 자막 | 영상 내 자막 + WebVTT + SRT | 토글·다운로드 |
| 썸네일 | 9:16 JPEG 또는 WebP | 보관함 카드·공유 미리보기 |
| 텍스트 | 제목, 1문장 설명, 해시태그 초안 | 복사 가능 |
| 이력 | 요청 요약, 승인 스토리보드, 모델/공급자 식별자, 정책 판정, 버전·시간 | 사용자용 요약 + 운영 감사 로그 |

기본 가시성은 `private`다. 공개 갤러리와 공유 링크는 별도의 명시적 동의가 있어야 하며, 공유 링크는 만료와 즉시 철회를 지원한다.

## 기능 요구사항

| ID | 요구사항 | 우선 |
|---|---|---|
| FR-01 | 사용자는 요청을 초안으로 저장하고, 필수값과 권리 고지를 확인한 뒤 제출할 수 있다. | P0 |
| FR-02 | 시스템은 제출 전 정책 검사 결과를 `통과`, `재작성 필요`, `검토 필요`, `차단`으로 표시한다. | P0 |
| FR-03 | 통과한 요청은 원작 고유 표현을 제거한 기획안과 15초 스토리보드를 만들고, 사용자의 승인을 받아야 생성할 수 있다. | P0 |
| FR-04 | 생성 작업은 큐·진행·실패·재시도 상태를 보존하며 중복 제출을 막는다. | P0 |
| FR-05 | 생성 결과를 품질·정책 검사 후 개인 보관함에 버전별로 전달한다. | P0 |
| FR-06 | 사용자는 결과를 다운로드, 삭제 요청, 만료 공유, 재생성 요청할 수 있다. | P1 |
| FR-07 | 운영자는 권리/안전 검토, 비공개 처리, 신고·삭제 처리와 감사 이력 확인을 할 수 있다. | P1 |

## 품질·신뢰 요구사항

- 사용자 콘텐츠와 결과물은 계정·프로젝트 권한으로 분리하고, 미디어 URL은 짧은 만료의 서명 URL로 제공한다.
- 정책 판정, 사용자 승인, 생성 요청, 공개/철회, 삭제는 감사 이벤트를 남긴다.
- 저장·삭제 보존 기간과 공급자 전송 데이터는 제출 전에 정책으로 설명한다.
- 재생 실패, 공급자 실패, 검토 대기는 모호한 성공 화면 대신 회복 가능한 상태와 다음 행동을 보여 준다.
- 접근성 기준으로 자막, 키보드 조작, 재생 컨트롤의 레이블, 색상 외 상태 표기를 제공한다.

## MVP 성공 가설과 수용 기준

| 가설/지표 | 출시 전 최소 증거 |
|---|---|
| 사용자는 원하는 장면을 제출할 수 있다. | 대상 사용자 5명 중 4명 이상이 도움 없이 요청→기획안 승인 흐름을 완주한다. |
| 15초 형식이 의도를 전달한다. | 서로 다른 3개 콘셉트 중 80% 이상이 세로 비율, 첫 2초 훅, 읽을 수 있는 자막, 완결된 한 장면 체크를 통과한다. |
| 금지 요청을 생성 전에 다룰 수 있다. | 준비된 권리·초상·미성년자·괴롭힘 테스트 세트를 100% 차단 또는 사람 검토 대기로 보낸다. |
| 비공개 전달이 이해된다. | 사용성 테스트 참가자 전원이 기본 공개 범위와 공유 철회 동작을 설명하거나 직접 수행한다. |

## 미해결 결정

1. 상용 AI 영상 공급자와 지역별 이용 가능 여부, 워터마크·상업권·보존 약관
2. 사용자당 생성 횟수/재생성 제한 및 결제 모델
3. 한국어 외 지원 언어의 TTS·자막 품질 기준
4. 라이선스 보유 B2B 요청을 위한 증빙 검토 절차와 법무 담당자
