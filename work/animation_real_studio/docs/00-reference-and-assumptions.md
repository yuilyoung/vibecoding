## 현재 적용한 가정

참고 영상의 세부를 추측하는 대신, 일반적인 세로 숏폼의 다음 문법만 MVP 가설로 둔다.

| 항목 | 가정 | 검증 방법 |
|---|---|---|
| 프레임 | 세로 9:16 | 생성 샘플의 메타데이터 검사 |
| 길이 | 한 장면을 전달하는 15초 | 사용자 인터뷰·샘플 시청 |
| 전개 | 첫 2초 훅 → 한 감정/갈등 → 여운 또는 반전 | 스토리보드 품질 체크 |
| 이해 보조 | 읽기 쉬운 내장 자막과 별도 자막 파일 | 음소거 시청 테스트 |
| 표현 | 일본 실사 드라마풍의 조명·구도는 가능하되, 특정 작품의 고유 표현은 재현하지 않음 | 권리·안전 테스트 세트 |

## 원본 접근 후 보완할 항목

원본을 사람이 합법적으로 확인할 수 있을 때 아래 표를 채우고, 이 문서의 가정만 갱신한다. 원본의 장면이나 대사를 제품 자산으로 복제하지 않는다.

| 관찰 항목 | 기록할 사실 | 설계에 미치는 영향 |
|---|---|---|
| 첫 장면 | 시선을 잡는 시각·문장 장치 | `vertical-short-director`의 훅 템플릿 |
| 쇼트 수·전환 | 컷 길이, 카메라 변화, 리듬 | 스토리보드 컷 예산 |
| 자막 | 위치, 문장 길이, 대비 | 자막 안전 영역·스타일 토큰 |
| 음향 | 대사·내레이션·효과음의 비중 | 오디오 생성/믹싱 요구사항 |
| 결말 | 반전·여운·CTA 여부 | 15초 결말 템플릿 |

## 설계 한계

이 패키지는 법률 자문이나 특정 AI 공급자의 상업 이용 허가를 보장하지 않는다. 공급자 약관, 사용 가능 지역, 워터마크, 데이터 보존, 상업 이용권은 출시 전 태스크 `ARS-018`에서 최신 원문으로 확인한다.
