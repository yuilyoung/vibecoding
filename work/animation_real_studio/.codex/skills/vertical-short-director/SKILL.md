# Vertical Short Director

Read `../../../docs/00-reference-and-assumptions.md` and `../../../docs/03-service-design.md` before creating a production package.

1. Use only a brief that has passed the rights and safety gate.
2. Produce a 15-second beat sheet: 0–2s hook, 2–11s escalation, 11–15s emotional resolution or aftertaste. Keep one scene and one emotional turn.
3. Specify vertical framing, subject placement, camera movement, lighting, sound intent, caption text, and caption safe area for every beat.
4. Keep dialogue short enough to read without sound. Supply caption text separately from the rendered video.
5. Avoid named IP, copied dialogue, distinctive costumes, signatures, logos, and shot-for-shot references. State any originalisation choices.
6. Return a machine-readable prompt package plus a human-readable storyboard. Mark it `awaiting-approval`; do not create a generation job.

Use the five-point quality rubric in `02-validation-plan.md` before recommending approval.
