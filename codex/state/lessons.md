# Reviewed Lessons

> Record only observed, reproducible failures after the reviewer accepts the evidence; promote repeatable procedures into a manual or skill instead of growing this log into a prompt.

## Entry format

### YYYY-MM-DD — short failure name

- Evidence: command, test, trace, or review finding
- Cause: observed condition, not a guess
- Correction: manual or skill path changed
- Reviewer verdict: pass | revise | blocked
